02. First Server

Understand scoping in Javascript and know to always use const if you can get away with it otherwise let.

Scoping handler om hvor din kode ligger henne, og hvilken kode der kan tilgå andet kode f.eks. er der global scope i en fil, det er det øverste lag, hvor alt andet kode i den fil kan tilgå hvad end det er, men hvis en const f.eks. er defineret inde i en funktion så kan den ikke tilgås udenfor den funktion
Det er godt at bruge const som udgangspunkt, da man f.eks. kan undgå side effects, den er nemmere for andre folk at forstå at den her ting skal ikke ændres + det er vist mere optimalt for koden.

Understand advanced things about functions in JavaScript.

Funktioner er first-class citizens i JS. De er værdier der kan gemmes i variabler, som så meget andet i JS. 


// 1. Declaration (Hoisting, kan blive kaldt tidligere i koden)
function addDeclaration(a, b) {
  return a + b
}

// 2. Expression (en funktion gemt i en variabel)
const addExpression = function (a, b) {
  return a + b
};

// 3. Arrow function (anonym funktion)
const add = (a, b) => a + b
